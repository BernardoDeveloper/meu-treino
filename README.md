# Meu Treino

Site simples para usar no celular na academia: instruções gerais e uma aba para cada treino (Peito, Tríceps, Bíceps, Perna), com fotos animadas de cada exercício.

Tudo fica em um único `index.html`, sem dependências.

Fotos: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (domínio público, Unlicense).

Ícones: [Lucide](https://lucide.dev) (ISC) e [Tabler Icons](https://tabler.io/icons) (MIT), só os usados, embutidos no HTML.
